## 公開対象と更新

`竹中工務店_第1回打合せ_Terabox提案資料_v3.html` のみを `index.html` として GitHub Pages に配置します。v2は比較用にリポジトリへ残します。その他の参考資料・要件文書・旧バージョンは Pages の配布物に含めません。

`main` ブランチの v3 HTML または `.github/workflows/pages.yml` を更新すると自動公開します。GitHub Actions の **Publish v3 to GitHub Pages** から手動実行も可能です。

提案資料のメモ・10項目の回答は閲覧中のブラウザ内に保存されます。v3は同一ブラウザ内の旧版の記録を初回に引き継ぎ、その後は別に保存します。コンセプト画面のデモ操作は再読込で初期化され、外部送信は行いません。
